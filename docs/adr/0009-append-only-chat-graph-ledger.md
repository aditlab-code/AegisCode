# 0009. Append-Only Event Ledger and Graph Storage for AI Conversations

We decided to transition from monolithic single-file chat serialization (`~/.aegis/chats/<id>.json`) to an append-only event ledger and graph storage architecture. Slices of metadata are decoupled into a high-performance index (`~/.aegis/sessions.json`), while conversation events, tool calls, and reasoning deltas are appended sequentially to individual JSONL ledgers (`~/.aegis/chats/<id>.jsonl`) using parent-pointer graph lineage. Heavy payloads (>4 KB) are offloaded to content-addressed raw blobs (`~/.aegis/blobs/<hash>.raw`). This guarantees O(1) writes during token streaming, reduces `GET /api/v1/chats` directory scanning from O(N) to O(1), eliminates full-tree memory rewrite latency, enables zero-rewrite conversation branching/forking, and maintains pure-Go zero-external-database principles with non-destructive legacy migration.
